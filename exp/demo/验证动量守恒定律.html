使用说明 · 验证动量守恒定律

实验目的：验证 m₁v₁₀ + m₂v₂₀ = m₁v₁ + m₂v₂（系统水平方向合外力为零）。
操作：
① 用 Edge / Chrome 打开本页面，点顶部「连接传感器」，按提示选串口（每次连接一台，两台光电门各连一次）。
② 「挡光片宽度 d」默认 0.010 m（按实际遮光片宽度改）；两车质量默认各 0.300 kg（黄色格可改）；选实验方式。
③ 点「开始记录」，让小车按碰撞顺序通过光电门：程序按挡光先后自动填入。
实验一（一动一静）3 次挡光顺序：① 入射车 m₁ 单独过门 → v₁₀（碰前）；② 碰后 m₁ 过门 → v₁；③ 碰后 m₂ 过门 → v₂。v₂₀ 自动为 0。两车各贴一片挡光片，碰后先后过同一光电门，也可用两个光电门各测一车。
手填示例：d=0.010 m、m₁=m₂=0.300 kg，碰前 Δt=0.020 s → v₁₀=0.500；碰后粘连两车各挡光 Δt=0.040 s → v₁=v₂=0.250；碰前动量 0.150、碰后 0.150，误差 0%。
④ 点「停止记录」收尾；检查/修改速度与质量（黄色格为质量，白色格为速度，「±」取反号）。
⑤ 点「数据计算」得到碰前、碰后总动量及相对误差；点「数据导出」保存 CSV；点 📷 保存表格图片。
无传感器时：可手动在表格里输入 v₁₀、v₂₀、v₁、v₂，同样可以计算与导出。
注意：Web Serial 需本地文件用 Edge/Chrome 打开并允许串口权限；气垫导轨需调水平，碰撞尽量正碰。
