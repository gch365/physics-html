操作指南：
1. 点击电路中节点数字1或2可以拨动开关切换充放电（1=充电，2=放电）
2. 三幅图像横轴固定从 0 开始，随时间增长整条曲线自动压缩显示全过程；I-t 图中充电电流为正、放电电流为负（反向），0 刻度在中间
3. 充/放电过程中 E、R 不可调，但 C 可调（电容器不锁定）；充电满电后改动 C 会自动重新接入电源，演示第二个过程：调大 C 再充电、调小 C 放电（Q=C·E 为目标）
4. 点击「重置图像」可清空曲线重新开始
