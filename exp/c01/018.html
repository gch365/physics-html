物理原理分析

当一个带电粒子以初速度v₀垂直进入匀强电场时，粒子会受到电场力的作用：

F = qE（电场力公式）
a = F/m = qE/m（竖直方向的加速度）

粒子运动分解为两个方向：

  • 水平方向（x轴）：匀速直线运动，速度 vₓ = v₀
  • 竖直方向（y轴）：初速度为0的匀加速运动，加速度 aᵧ = qE/m

经过时间t，粒子的位置为：

x = v₀·t
y = 0.5·aᵧ·t² = 0.5·(qE/m)·t²

当粒子离开电场时，可以得到偏移量公式：

y = (q·U·L²) / (2·m·d·v₀²)

其中U为两极板电压，L为极板长度，d为极板间距。

偏转角度θ由粒子离开电场时的速度方向确定：

tanθ = vᵧ/vₓ = (qE·t)/(m·v₀)
