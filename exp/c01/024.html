动态平衡问题之矢量三角形法

OB绳角度: 90° 90° → 180°
提示：拖动B点可旋转OB绳，其他保持不变

矢量三角形法

1、适用条件
（1）物体受三个力作用；
（2）其中一个力为恒力（大小、方向均不变），通常为重力，也可以是其他力；
（3）另个力的方向不变，大小变化；或者大小不变，方向改变；
（4）第三个力大小、方向均发生变化的问题。
2、方法:将三个力的矢量首尾相连构成闭合三角形。根据边的长短变化来判断力的大小变化。
力的合成: 三个力按顺序首尾相连形成闭合三角形
TAO + TBO + G = 0
注：OB从竖直向上(90°)转动到水平向左(180°)

受力平衡方程

水平方向平衡 (x方向):
TAOx + TBOx + Gx = 0
⇒ TAO·cos(60°) + TBO·cos(θBO) + 0 = 0
竖直方向平衡 (y方向):
TAOy + TBOy + Gy = 0
⇒ TAO·sin(60°) + TBO·sin(θBO) - G = 0
力的合成: 三个力按顺序首尾相连形成闭合三角形
TAO + TBO + G = 0
