09 合力与分力 —— 平行四边形定则
左：力的平行四边形　右：合力大小随夹角 α 的变化曲线（拖动顶点改变方向，或点「自动变角」自动扫描 α）
两个共点力合成遵循平行四边形定则：以 F₁、F₂ 为邻边作平行四边形，对角线即合力 F。 由余弦定理 F = √(F₁² + F₂² + 2F₁F₂·cosα)，随夹角 α 增大合力单调减小， 取值范围为 |F₁ − F₂| ≤ F ≤ F₁ + F₂（α = 0 时最大，α = 180° 时最小）。

结论：合力可以大于、等于或小于任一分力；
α = 0°：F = F₁ + F₂（最大）；
α = 90°：F = √(F₁² + F₂²)；
α = 180°：F = |F₁ − F₂|（最小）。
