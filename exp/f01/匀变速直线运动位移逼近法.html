微元思想：把 [0, T] 等分为 n 段，每段长 Δt = T/n。取每段左端速度 vᵢ = v₀ + a·i·Δt 作小矩形，面积之和 s₁ = Σ vᵢ·Δt = v₀T + ½aT²·(n−1)/n。
当 n → ∞ 时 s₁ → s₂ = v₀T + ½aT²，即匀变速直线运动的位移公式；差值 Δs = ½aT²/n → 0。
