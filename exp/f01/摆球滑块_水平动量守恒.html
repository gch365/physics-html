原题解析

水平面光滑，系统在水平方向不受外力，故水平方向动量守恒。设小车(含立柱)质量 M、摆球质量 m、绳长 L，小球由静止拉至右侧 θ₀ 处。

px = (M+m)·ẋ + m·L·cosθ·θ̇ = 常量 = P₀
情景① 同时释放小球与小车

二者均由静止释放 ⇒ 初动量 P₀ = 0，全程水平动量恒为 0，质心水平位置不变。由人船模型：

M·Δx车 + m·Δx球 = 0 ⇒ |Δx车|max = (m/(M+m))·L·sinθ₀

小球来回摆动时，小车在固定范围内往复运动（不前进、不后退）。质心始终停在释放时的水平位置。

情景② 先放球，摆到最低点再释放小车

释放小车前小车被按住不动，小球从 θ₀ 摆到最低点机械能守恒：

½m·v₀² = m·g·L(1−cosθ₀) ⇒ v₀ = √(2gL(1−cosθ₀))

此刻小球已有水平速度 v₀（向左）。就在这一瞬间释放小车，之后水平方向再无外力，守恒动量不为零：

P₀ = m·v₀ ≠ 0 ⇒ Vcm = P₀/(M+m) 恒定

于是系统在「相对质心的往复摆动」之上叠加一个向左的匀速平移——小车随质心逐步向左滑去，正对应实验里「小球在左半区时小车左移、到最高点瞬时停下、摆回右半区时小车右移，整体却逐段向左」。
