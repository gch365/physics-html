地球自转（GZZX郭老师）
万有引力 = 向心力 + 重力
曲面（自转扫过）赤道 / 经线弧三个矢量
原文件构造：赤道 = Circle(O, 10)，P 在赤道上；P′ = Rotate(P, 角度°, O)；N(0,0,10)、S(0,0,−10)；圆弧P = CircumcircleArc(S,P,N)、圆弧P′ 同理；曲面 = Surface(圆弧P, 角度°, zAxis)（青色，自转扫过的球面月牙）。A 在圆弧P 上，B = (0,0,z(A))，C = Dilate(A, 4/5, B)。三个矢量：万有引力 = Vector(A,O)、向心力 = Vector(A,C)、重力 = Vector(A,D)（D = O + (−向心力)），虚线为线段 CO、线段 DO。
说明：本文件在 GeoGebra 中是 3D 视图（euclidianView3D，正交投影，xAngle = 13°、zAngle = −4.62°）。此处用原生 Canvas 做等价的正交投影绘制，默认视角略微抬高以便观察，可在图上按住鼠标拖动旋转视角。向心力矢量长度按原文件的 Dilate 比 4/5 绘制（即 0.2×到自转轴距离），为示意长度，并非与万有引力同一比例尺。
