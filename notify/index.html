📖 使用说明（安装 / 首次使用 / 通知 / 作业栏）
【安装】把压缩包里的文件全部解压到同一个文件夹（例如 D:\教室点名\），双击 classroom_rollcall.exe 运行。压缩包不含任何学生名单文件；班级名单与课表由程序在「创建班级」时从私有仓库按班拉取，这台电脑需要能上网。

【首次使用】
① 打开「系统设置」→「基本设置 → 班级管理」，填写学校、年级、班号，点「➕ 创建班级」。
② 创建后程序立刻拉取「这一个班」的名单与课表，界面显示「已从私有仓库拉取本班：XX 名学生、XX 节课」；本机只保存已创建班级的数据，不会出现全校名单。
③ 云端没有该届数据时班级仍会创建成功（空名单），到「学生名单」「课表设置」自行粘贴导入。
④ 每个教室默认最多创建 2 个班级，确实需要更多请联系管理员解锁。
⑤ 创建时断网或提示拉取失败，联网后点「☁ 从云端补全当前班」即可重试。
⑥「系统设置 → Web 与仓库 → 云端班级名单」可查看仓库与只读令牌；只读令牌由管理员统一配置，请勿改成可读写令牌，也不要外传。

【通知弹屏与秒级推送】
① 平时用手机或浏览器打开本页发通知，网页已内置实时推送，保存后各教室 1~2 秒内自动拉取。请确认本页「⚡ 实时推送」显示已连接；若显示「未开启」，点「保存并连接」，否则教室只能等轮询。
② 通知正文含「通知」「重要通知」「重要消息」时，课间 / 放学后会在屏幕正中弹出半屏通知卡，并用电脑语音播报三遍；上课、周休、上课前 30 秒不弹。
③ 弹卡不会自动消失，点卡片其它位置也没用，只有右下角「关闭」（或按 Esc）能关掉；切换到上课时由程序按作息自动收起。

【桌面作业栏】右下角三个按钮：电源 = 彻底关闭、铅笔 = 编辑作业 / 值日、红色 ✕ = 本次隐藏。彻底关闭需输入确认码 123，关闭后重启程序也不会自动打开，要到「系统设置 → 基本 → 桌面作业栏」重新勾选。点作业栏任意位置（含铅笔按钮）可直接打开「班级桌面大屏设置」面板，一个窗口内含「今日作业 / 班干部值周 / 卫生值日」三页。通知横幅与侧边条都可按住拖动，滚轮可缩放。

【其它】首次运行若被 Windows SmartScreen 拦截，点「更多信息」→「仍要运行」。desktop_board.exe 是桌面大屏独立进程，主程序会自动拉起，无需手动双击。
