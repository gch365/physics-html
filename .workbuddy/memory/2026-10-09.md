## 155.html 第 7 轮（等势面开关失效 + 面板重排）
郭老师两条：「🖱 点击画布放置 / 0°向右 90°向下 / 放入时自动开始运动」三行放到「显示运动轨迹」后、
删掉「+ 放入试探电荷」按钮；「显示等差等势面（叠加层）」点了不显示。

**等势面点不开的根因（自己写的补丁 Bug）**：`eqBox.onchange = function(){ toggleEq(); }`。
用户勾上 → checked=true → onchange 里 `toggleEq()` 又按 `on = !eqOn()` **取反** → 立刻翻回 false，
表现为「点了没反应」。改成 `toggleEq(eqBox.checked)`（按当前勾选状态同步，不取反）。
另加 `__eqWasOn` 追踪：关掉再打开时强制 `eqDirty = true` 重渲一次。

**删按钮不能真删 HTML 元素**：原脚本 `setupEvents()` 里是 `document.getElementById('add-test').onclick = ...`，
元素没了 → 抛 `Cannot set properties of null` → **整段 setupEvents 中断**，后面
`sourceCharges is not defined` / `width is not defined`，画布全黑。
解法：补丁在解析期（早于 onload→setupEvents）补一个 `display:none` 的隐藏占位 `<button id="add-test">`
塞进 `#test-list`，原脚本照常绑上，界面上看不到按钮。
→ 以后删任何原脚本会引用的元素，都要在补丁里留隐藏占位。

**回灌补丁字面量必须转义 `\r`**：`.patch155.js` 是 CRLF，`esc()` 只处理了 `\n`，
裸 CR 进 JS 字符串字面量 → `Invalid or unexpected token` → 原脚本整段不执行。
现在 `.tmp_re.py`（回灌脚本）里统一 `p.replace('\r\n','\n')` 再 `\\`→`\\\\`、"`→`\\"`、`\n`→`\\n`。
自查方式：从 HTML 里正则抠出 `window.__PATCH_155 = "..."`，`eval` 还原后用 `new Function(t)` 验语法。

**移动 UI 行前先查原位置有没有**：这三行原本就在青色卡片底部，移到「显示运动轨迹」后变成两份，
截图才看出来 → 删掉卡片里那份。改完必须截图看一眼面板。

## 工具坑（重要）
- **Playwright 的 `page.evaluate` 走页面里的 `window.eval`** → 155 的 eval 桥接
  （`window.eval = src + window.__PATCH_155`）会把它当补丁重跑，报
  `TypeError: result is not a function`，整段 evaluate 全废。
  **解法：用 `page.context().newCDPSession(page)` + `Runtime.evaluate {returnByValue:true, awaitPromise:true}`**，
  走 V8 通道，绕过被重写的 eval。
- `agent-browser` 守护进程跑多了全画布 `getImageData` 会**彻底卡死**（CDP timeout，
  之后所有命令 EOF，重启不了）→ 改用 playwright-core + CDP 脚本更稳、更快。
- playwright 只装了 `playwright-core`（在 `~/.workbuddy/binaries/node/workspace/node_modules`），
  用它时 `NODE_PATH=<workspace>/node_modules node xxx.js`，且要显式给 `executablePath`：
  `C:/Users/gchui/AppData/Local/ms-playwright/chromium-1228/chrome-win64/chrome.exe`。
- `AGENT_BROWSER_EXECUTABLE_PATH` 指向 Edge（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`）
  时 `agent-browser open` 经常卡住；**不设这个变量用自带 chromium 反而是通的**。
- 回灌补丁字面量的自检别用 `atob`/`charCodeAt` 判断加密块：155 的加密是
  `})( "<base64 密文>", 175 )` + 混淆函数名（`_z1wbasb` 之类），自检用
  `re.search(r'\}\)\("([A-Za-z0-9+/=]{200,})",\s*\d+\)', html)`。
- 回灌脚本别漏 `io.open(target,'w')`（写过一次，assert 报错才发现根本没写进去，白查半天）。
