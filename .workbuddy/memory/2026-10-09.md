## 工具坑（重要）
- **Playwright 的 `page.evaluate` 走页面里的 `window.eval`** → 155 的 eval 桥接
  （`window.eval = src + window.__PATCH_155`）会把它当补丁重跑，报
  `TypeError: result is not a function`，整段 evaluate 全废。
  **解法：用 `page.context().newCDPSession(page)` + `Runtime.evaluate {returnByValue:true, awaitPromise:true}`**，
  走 V8 通道，绕过被重写的 eval。
- `agent-browser` 守护进程跑多了全画布 `getImageData` 会**彻底卡死**（CDP timeout，
  之后所有命令 EOF，重启不了）→ 改用 playwright-core + CDP 脚本更稳、更快。
- playwright 只装了 `playwright-core`（在 `~/.workbuddy/binaries/node/workspace/node_modules`），
  用它时 `NODE_PATH=<workspace>/node_modules node xxx.js`，且要显式给 `executablePath`：
  `C:/Users/gchui/AppData/Local/ms-playwright/chromium-1228/chrome-win64/chrome.exe`。
- `AGENT_BROWSER_EXECUTABLE_PATH` 指向 Edge（`C:/Program Files (x86)/Microsoft/Edge/Application/msedge.exe`）
  时 `agent-browser open` 经常卡住；**不设这个变量用自带 chromium 反而是通的**。
- 回灌补丁字面量的自检别用 `atob`/`charCodeAt` 判断加密块：155 的加密是
  `})( "<base64 密文>", 175 )` + 混淆函数名（`_z1wbasb` 之类），自检用
  `re.search(r'\}\)\("([A-Za-z0-9+/=]{200,})",\s*\d+\)', html)`。
- 回灌脚本别漏 `io.open(target,'w')`（写过一次，assert 报错才发现根本没写进去，白查半天）。
