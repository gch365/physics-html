
## 人船模型：新增鼠标拖动小人（质心不变/船反向移动）
- 文件：exp/f01/（49）动量守恒人船模型-仿写.html（首页「动量守恒·人船模型」卡片 + featured 精选卡指向它）。页面两个场景：1 悬球摆球 / 2 经典人船，首页链接默认 scene=1，需点「经典人船」按钮或加 ?scene=2。
- 需求：在人船场景用鼠标拖动人的位置，船随之按动量守恒反向移动。
- 实现：①状态加 dragging/hoverPerson；②drawBoat 里小人在拖动时停止迈步(walking=0)并加提示文字；③用 pointerdown/move/up/cancel（同时支持鼠标+触屏，cv.style.touchAction=none）做拖动。核心：坐标换算 boatCanvasXY 用 getBoundingClientRect×(cv.width/r.width)，兼容 CSS 缩放与 body.zoom；nearPerson 命中判定(|mx-px|<36, deckY-72..+10)；dragPersonTo 由鼠标 x 反推 sRen=(mx-BOAT_X0)/S2 → srel=sRen·(1+mb)/mb → clamp[0,LB] → boatT=srel/VR_BOAT(1.2，与 boatState 的 vr 一致)。begin drag 时 playing=false 自动暂停。
- 物理：sRen=srel·mb/(1+mb)、sChuan=srel/(1+mb)，保证 m人·S人=m船·S船（质心不动），人右移船左退。
